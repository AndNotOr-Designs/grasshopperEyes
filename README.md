# grasshopperEyes

Using 2 OSEEP 10mm RGB LEDs, grasshopper's eyes will light up based on specific MQTT commands:
1) grasshopper wake up: dark orange immediately
2) grasshopper reviewing command: blue
3) grasshopper speaking back: red
4) grasshopper 'sleeping': 'orange' even though it's more yellow in nature, and set to 50% brightness
5) grasshopper misunderstanding: 'orange' even though it's more yellow in nature, and set to 50% brightness

Grasshopper's skull is adapted from:
https://www.crealitycloud.com/model-detail/skull-printing-model?source=9&profileId=6a95b3ba03962b4e69d14d9e

Inside has been hollowed out to help with inserting LEDs into eyeball sockets and to allow for circuitry to be installed in his "brain".

Gcode file is too big to include in the repository, but is saved in my onedrive and fusion repository.
